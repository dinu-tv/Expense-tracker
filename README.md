# Expense Tracker Application

A simple, responsive, and feature-rich Personal Expense Tracker web application built with Vanilla HTML, CSS, and JavaScript.

**Features**

Dashboard Overview:Real-time summary cards displaying Current Balance, Total Income, and Total Expenses.

Transaction Management:Add, edit, and delete income and expense records dynamically.

Search & Filter:Filter transactions by type, category, or keyword search.

Data Persistence:Uses browser localStorage to save transactions across sessions.

CSV Export:Download all transaction data as a CSV file.

Responsive Design:Fully optimized for both desktop and mobile viewports.

**Tech Stack**
Frontend:HTML5, CSS3, JavaScript (ES6+)
Storage:Browser LocalStorage API

How to Run Locally
1.Clone or download this repository.
2.Open index.html directly in any modern web browser (or use VS Code Live Server).
